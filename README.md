# Fitness & Expense Tracker 🏋️‍♂️ 💰

A sleek, Apple iOS-inspired Web Application for tracking gym workouts and daily expenses.

## 🚀 Live Demo (GitHub Pages)
👉 **[https://dwightbuma-at.github.io/EXPENSE-AND-GYM-TRACKER/](https://dwightbuma-at.github.io/EXPENSE-AND-GYM-TRACKER/)**

---

## ⚡ 100% Offline & No Wi-Fi Needed
This application is completely self-contained and works with **zero internet connection**:
- **Local Scripts**: Tailwind CSS and Lucide Icons are bundled locally in `assets/js/`.
- **Progressive Web App (PWA)**: Includes `sw.js` (Service Worker) and `manifest.json`. Once opened on your phone or computer, it caches all assets so you can use it anytime anywhere in Airplane Mode.
- **Local Storage**: All workout sessions and expenses are saved directly on your device using `localStorage`.

---

## 📁 Features
1. **Gym Tracker**:
   - **Chest & Back** routine
   - **Arm Day** routine
   - **Leg Day** routine
   - Log Sets, Reps, and Weight (with KG / LBS toggle)
   - Save animation (Saving... ➔ Saved!)
   - Workout timeline grouped by date, with sets chronologically organized under each exercise
   - Delete individual sets or entire dates
2. **Expense Tracker**:
   - Quick expense logging (Amount, Category, Notes)
   - Real-time total daily calculation
   - Filter and view past daily transaction logs
3. **Apple iOS Aesthetic**:
   - Clean outlined cards, spring micro-interactions, responsive mobile and desktop layouts.

---

## 💻 How to Run Locally
Just double-click `index.html` in any browser! No build step, no npm, and no Wi-Fi required.
